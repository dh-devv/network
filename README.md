# 🌐 Network

네트워크(Network)를 학습하며 이론, 프로토콜, 데이터 전송 과정, 실습 내용을 정리하는 저장소입니다.

> **목표는 단순한 필기가 아닌, 학습한 내용을 직접 정리하고 기록하여 꾸준히 성장하는 것입니다.**

- Wireshark를 활용한 패킷 분석
