# 인터넷과 네트워크 프로토콜

# 인터넷(Internet)

인터넷은 전 세계에 존재하는 수많은 네트워크들이 서로 연결되어 만들어진 거대한 네트워크이다.

그래서 인터넷을

**Network of Networks**

즉, **네트워크들의 네트워크**라고 표현하기도 한다.

```text
LAN ──┐
      │
LAN ──┼── Internet ── LAN
      │
WAN ──┘
```

각각의 네트워크가 독립적으로 존재하더라도  
Router 등을 통해 서로 연결하면 다른 네트워크에 있는 장비와 통신할 수 있다.

---

## 인터넷을 사용하는 이유

인터넷을 통해 멀리 떨어진 컴퓨터끼리 데이터를 주고받을 수 있다.

예를 들면

- 웹사이트 접속
- 이메일 전송
- 파일 다운로드
- 클라우드 서비스 사용
- 서버 접속

등이 모두 네트워크 통신을 이용한다.

---

# Protocol

## 프로토콜(Protocol)이란?

프로토콜은 네트워크에 연결된 장비들이 서로 통신하기 위해 사용하는 **공통된 규칙 또는 약속**이다.

사람도 서로 다른 언어를 사용하면 대화하기 어려운 것처럼  
컴퓨터 역시 서로 같은 통신 규칙을 사용해야 데이터를 정상적으로 주고받을 수 있다.

---

## 일반적인 정의

네트워크에 있는 컴퓨터와 장비들이 효율적으로 통신하기 위해 사용하는 여러 가지 규칙이다.

---

## 기술적인 정의

통신하는 장비들 사이에 미리 합의된 규칙의 집합으로  
데이터의 형식, 의미, 전송 방법 등을 정의한다.

예를 들어 다음과 같은 내용을 정할 수 있다.

- 데이터의 형식
- 데이터를 보내는 방법
- 데이터를 받는 방법
- 송신자와 수신자를 구분하는 방법
- 오류가 발생했을 때 처리하는 방법

---

# 프로토콜이 필요한 이유

만약 컴퓨터마다 서로 다른 방식으로 데이터를 전송한다면 정상적인 통신이 어렵다.

예를 들어 A 컴퓨터가

```text
주소 | 데이터 | 오류 확인 정보
```

순서로 데이터를 보냈는데

B 컴퓨터가

```text
데이터 | 오류 확인 정보 | 주소
```

순서라고 생각한다면 데이터를 제대로 해석할 수 없다.

따라서 송신자와 수신자가 같은 규칙을 사용해야 한다.

```text
송신자
  │
  │ 같은 Protocol 사용
  ▼
Network
  │
  ▼
수신자
```

---

# 대표적인 네트워크 프로토콜

네트워크에서는 하나의 프로토콜만 사용하는 것이 아니라  
목적에 따라 여러 프로토콜을 함께 사용한다.

### IP

목적지까지 데이터를 전달하기 위한 주소와 경로에 관련된 프로토콜이다.

### TCP

데이터가 안정적으로 전달될 수 있도록 연결과 전송을 관리한다.

### UDP

TCP보다 단순한 방식으로 빠르게 데이터를 전달한다.

### HTTP

웹 브라우저와 웹 서버가 데이터를 주고받을 때 사용한다.

### DNS

도메인 이름을 IP Address로 변환할 때 사용한다.

# 인터넷과 프로토콜의 관계

인터넷에는 매우 많은 종류의 컴퓨터와 네트워크 장비가 연결되어 있다.

장비의 제조사나 운영체제가 다르더라도  
서로 같은 표준 프로토콜을 사용하면 통신할 수 있다.

```text
Windows PC
     │
     │ TCP/IP
     ▼
  Internet
     ▲
     │ TCP/IP
     │
Linux Server
```

따라서 인터넷이 정상적으로 동작하기 위해서는  
서로 통신할 수 있는 공통된 프로토콜이 필요하다.

---

# 핵심 정리

```text
Network
= 장비와 장비를 연결하여 데이터를 주고받는 통신망

LAN
= 제한된 지역의 네트워크

WAN
= 넓은 지역 또는 여러 LAN을 연결하는 네트워크

Internet
= 전 세계의 수많은 네트워크가 연결된 네트워크

Protocol
= 네트워크에서 장비끼리 통신하기 위한 공통 규칙
```

네트워크를 처음 배울 때는 각각의 용어를 따로 암기하는 것보다

```text
PC → LAN → Router → WAN → Internet
```

이라는 전체 흐름 안에서 생각하는 것이 이해하기 쉬웠다.
