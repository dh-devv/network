# 네트워크 기초

## 네트워크(Network)란?

네트워크는 한 장비와 다른 장비를 통신 매체(Media)를 통해 연결하여  
서로 정보와 데이터를 주고받을 수 있도록 구성한 통신망이다.

쉽게 말하면,

**컴퓨터와 컴퓨터가 서로 데이터를 주고받을 수 있도록 연결한 것**이라고 이해할 수 있다.

단순히 연결하는 것뿐만 아니라 데이터를 정확하고 효율적으로 전달하는 것도 중요하다.

---

## 네트워크를 쉽게 생각해보기

수업에서는 네트워크를 고속버스에 비유해서 이해했다.

```text
출발지                이동 경로                도착지
PC A    ────────── Network ──────────>    PC B
```

버스 터미널에서 사람이 출발하여 다른 터미널로 이동하는 것처럼  
네트워크에서도 한 장비에서 출발한 데이터가 네트워크를 거쳐 다른 장비에 도착한다.

네트워크에서는 PC와 같은 장비를 보통 **Host 또는 End Device**라고 부른다.

### 내가 이해한 형태

```text
[PC A]
   │
   │ 데이터 전송
   ▼
[Network]
   │
   ▼
[PC B]
```

중간의 Network에는 Switch, Router 등의 여러 네트워크 장비가 존재한다.

---

## 네트워크를 사용하는 이유

네트워크가 없다면 필요한 데이터를 다른 컴퓨터로 직접 옮겨야 한다.

하지만 네트워크를 사용하면 여러 장비 사이에서 자원을 쉽게 공유할 수 있다.

대표적인 예시는 다음과 같다.

- 파일 공유
- 프린터 공유
- 데이터 공유
- 서버 접속
- 인터넷 접속

예를 들어 같은 학교 네트워크에 연결된 여러 컴퓨터가 하나의 프린터를 함께 사용할 수도 있다.

---

## 데이터와 신호

컴퓨터에서 만들어진 데이터가 항상 그대로 전송되는 것은 아니다.

통신 방식에 따라 데이터를 전송 가능한 신호의 형태로 변환해야 할 수 있다.

### 변조(Modulation)

전송할 데이터를 통신 매체를 통해 전달할 수 있는 신호 형태로 변환하는 과정이다.

### 복조(Demodulation)

전송받은 신호에서 원래 데이터를 다시 복원하는 과정이다.

```text
데이터
  │
  ▼
변조
  │
  ▼
전송 신호
  │
  ▼
통신 매체
  │
  ▼
복조
  │
  ▼
데이터
```

처음에는 변조와 복조를 각각 '버스를 타는 것', '버스에서 내리는 것'이라고 생각하면 이해하기 쉬웠다.

다만 모든 네트워크 통신에서 변조와 복조라는 표현을 동일하게 사용하는 것은 아니며,
전송 방식에 따라 신호를 처리하는 방법은 달라질 수 있다.

---

## 정리

네트워크의 가장 기본적인 흐름은 다음과 같다.

```text
송신 장비 → 네트워크 → 수신 장비
```

그리고 네트워크 내부에서는 여러 통신 장비와 통신 매체가 사용되어  
데이터가 목적지까지 전달될 수 있도록 한다.
