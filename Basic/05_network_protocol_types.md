# 네트워크 프로토콜의 규칙과 종류

## 프로토콜이란?

네트워크 프로토콜(Network Protocol)은 장비들이 서로 통신하기 위해 지키는 공통된 규칙이다.

한국어로 대화하려면 서로 한국어를 이해해야 하는 것처럼, 장비도 서로 이해할 수 있는 통신 규칙을 사용해야 한다. 같은 네트워크 안에서 통신할 때도 프로토콜이 필요하다.

프로토콜에서 정하는 내용에는 다음과 같은 것들이 있다.

- 데이터를 어떤 형식으로 구성할지
- 송신자와 수신자를 어떻게 구분할지
- 언제 데이터를 보내고 어떻게 응답할지
- 오류나 데이터 손실을 어떻게 처리할지

통신 규칙에는 논리적인 절차뿐 아니라 신호와 전송 매체에 관한 물리적인 규칙도 포함된다. 다만 케이블이나 커넥터 자체를 프로토콜이라고 부르는 것은 아니다.

## TCP/IP

인터넷에서 사용하는 대표적인 프로토콜 모음이 TCP/IP이다.

TCP와 IP 하나씩만 사용하는 것이 아니라, Ethernet, TCP, UDP, IP, HTTP, DNS 등 여러 프로토콜이 계층별로 역할을 나누어 통신한다.

```text
HTTP  → 웹 요청과 응답
TCP   → 순서가 있는 신뢰성 있는 데이터 전송
IP    → 목적지 IP 주소를 기준으로 패킷 전달
Ethernet → 같은 링크에서 프레임 전달
```

## LAN과 WAN에서 사용하는 통신 기술

| 구분 | 대표적인 프로토콜·기술 |
|------|------------------------|
| LAN | Ethernet, Token Ring, FDDI, 무선 LAN(IEEE 802.11) |
| WAN | HDLC, PPP, Frame Relay |

Token Ring과 FDDI는 과거 LAN 기술을 공부할 때 함께 등장한다. 무선 LAN도 단순히 선이 없는 연결이 아니라 IEEE 802.11과 같은 표준에 따라 통신한다.

LAN과 WAN은 네트워크의 범위에 따른 구분이고, 프로토콜은 데이터를 주고받는 규칙에 따른 구분이다. Ethernet도 WAN 서비스에 쓰일 수 있으므로 위 표가 사용 범위를 제한하는 것은 아니다.
