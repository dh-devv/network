# 네트워크 통신 매체와 장비

## 통신 매체(Media)

통신 매체는 한 장비에서 다른 장비로 데이터를 전달할 때 사용하는 전송 경로이다.

쉽게 말하면 네트워크 장비들을 실제로 연결해 주는 길이라고 생각할 수 있다.

대표적인 유선 통신 매체에는 다음과 같은 것들이 있다.

### 1. 트위스트 페어 케이블(Twisted Pair Cable)

일반적인 LAN 환경에서 많이 사용하는 케이블이다.

흔히 사용하는 UTP 케이블도 트위스트 페어 케이블의 한 종류이다.

두 개의 선을 한 쌍(Pair)으로 꼬아서 사용하며,
일반적인 Ethernet용 UTP 케이블에는 4쌍, 총 8가닥의 선이 들어 있다.

```text
1 Pair = 2가닥

일반적인 UTP Cable
= 4 Pair
= 총 8가닥
```

선을 꼬아서 사용하는 이유 중 하나는 외부에서 발생하는 전기적 간섭을 줄이기 위해서이다.

---

### 2. 동축 케이블(Coaxial Cable)

중앙의 도체를 절연체와 외부 도체가 감싸는 형태의 케이블이다.

과거 Ethernet 환경이나 케이블 TV 등에서 많이 사용되었다.

---

### 3. 광섬유 케이블(Fiber Optic Cable)

전기 신호 대신 빛을 이용하여 데이터를 전송한다.

장거리에서도 빠르게 데이터를 전달할 수 있고 전자기 간섭의 영향을 적게 받는다는 특징이 있다.

대용량 데이터를 장거리로 전송하는 네트워크에서 많이 사용된다.

---

# 네트워크 장비

네트워크에는 데이터를 목적지까지 전달하기 위한 여러 장비가 존재한다.

대표적으로 Hub, Switch, Router가 있다.

---

## Hub

Hub는 여러 장비를 하나의 네트워크에 연결하는 장비이다.

Hub로 데이터가 들어오면 목적지를 직접 판단하지 않고  
연결된 여러 포트로 데이터를 전달한다.

```text
        ┌── PC A
        │
Hub ────┼── PC B
        │
        └── PC C
```

따라서 Hub는 데이터를 저장하는 공간이라기보다  
들어온 신호를 다른 포트로 전달하는 장비라고 이해하는 것이 정확하다.

현재의 일반적인 Ethernet 네트워크에서는 Hub보다 Switch를 주로 사용한다.

---

## Switch

Switch는 같은 네트워크에 있는 여러 장비를 연결하는 장비이다.

Switch는 **MAC Address**를 이용하여 데이터가 어느 장비로 가야 하는지 판단하고  
필요한 포트로 Ethernet Frame을 전달한다.

```text
PC A ──┐
       │
PC B ──┼── Switch
       │
PC C ──┘
```

따라서 Switch를 단순히 장비를 연결했다가 끊는 장치라고 보기보다는

**같은 LAN 안에서 데이터를 적절한 장비로 전달하는 장치**

라고 이해하는 것이 좋다.

---

## Router

Router는 서로 다른 네트워크를 연결하는 장비이다.

Switch가 주로 같은 네트워크 내부의 통신을 담당한다면  
Router는 다른 네트워크로 데이터를 전달하는 역할을 한다.

Router는 목적지의 **IP Address**와 Routing 정보를 이용하여  
패킷을 어느 방향으로 보낼지 결정한다.

```text
LAN A ── Router ── LAN B
```

인터넷은 수많은 서로 다른 네트워크가 Router를 통해 연결되어 만들어진다.

---

# Switch와 Router 차이

```text
Switch
→ 같은 네트워크 내부의 장비 연결
→ MAC Address 사용
→ Ethernet Frame 전달

Router
→ 서로 다른 네트워크 연결
→ IP Address 사용
→ IP Packet 전달
```

처음에는 둘 다 컴퓨터를 연결하는 장비처럼 보이지만  
실제로는 통신하는 범위와 사용하는 주소가 다르다.
