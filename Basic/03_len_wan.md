# LAN과 WAN

네트워크는 구성되는 범위에 따라 여러 종류로 나눌 수 있다.

기초적으로 가장 많이 사용하는 구분은 LAN과 WAN이다.

---

# LAN

## LAN(Local Area Network)이란?

LAN은 **제한된 지역 안에서 여러 컴퓨터와 네트워크 장비를 연결한 근거리 통신망**이다.

예를 들면 다음과 같은 장소에서 LAN을 구성할 수 있다.

- 집
- 학교
- 회사
- 컴퓨터실

일반적으로 사용자가 직접 관리할 수 있는 비교적 작은 범위의 네트워크이다.

---

## LAN의 특징

- 비교적 좁은 지역에서 사용한다.
- 일반적으로 높은 속도로 통신할 수 있다.
- 조직이나 사용자가 직접 관리하는 경우가 많다.
- Switch를 이용하여 여러 장비를 연결할 수 있다.
- Ethernet이 많이 사용된다.

LAN을 구성할 때 사용하는 대표적인 장비는 Switch이다.

```text
PC A ──┐
       │
PC B ──┼── Switch
       │
PC C ──┘
```

---

# WAN

## WAN(Wide Area Network)이란?

WAN은 **멀리 떨어진 네트워크들을 연결하는 광역 통신망**이다.

쉽게 생각하면 여러 LAN을 서로 연결한 네트워크라고 볼 수 있다.

```text
LAN A
  │
Router
  │
======== WAN ========
  │
Router
  │
LAN B
```

지역적으로 멀리 떨어진 학교, 회사 또는 데이터센터 등을 서로 연결할 때 WAN을 사용할 수 있다.

---

## WAN의 특징

- 넓은 지역을 연결한다.
- 여러 LAN을 서로 연결할 수 있다.
- Router가 중요한 역할을 한다.
- 통신 사업자 또는 ISP의 네트워크를 이용하는 경우가 많다.
- LAN보다 관리해야 하는 범위와 구조가 복잡하다.

---

# 집으로 생각해보기

집의 네트워크를 예로 들면 이해하기 쉽다.

```text
내 PC
  │
Switch / Wi-Fi
  │
공유기
  │
Internet
```

집 안에 있는 PC, 스마트폰 등의 장비가 구성하는 네트워크는 LAN으로 볼 수 있다.

그리고 집의 Router를 거쳐 ISP의 네트워크와 인터넷으로 나가게 된다.

처음 배울 때는

```text
Router 안쪽 = LAN
Router 바깥쪽 = WAN
```

이라고 생각하면 LAN과 WAN의 차이를 이해하기 쉽다.

다만 이것은 이해를 돕기 위한 단순한 표현이고,
LAN과 WAN의 실제 구분은 네트워크가 구성되는 범위와 목적을 기준으로 한다.

---

# Gateway

Gateway는 한 네트워크에서 다른 네트워크로 이동하기 위해 거치는 출입구 역할을 한다.

PC에서 다른 네트워크로 데이터를 보내야 할 때  
일반적으로 **Default Gateway**로 지정된 장비에 데이터를 먼저 전달한다.

가정에서는 보통 공유기의 LAN IP Address가 Default Gateway가 된다.

예를 들어

```text
PC IP            : 192.168.0.10
Default Gateway  : 192.168.0.1
```

이라면 같은 네트워크 밖으로 데이터를 보내야 할 경우  
PC는 먼저 `192.168.0.1`로 데이터를 전달한다.

---

# Switch와 Gateway는 같은 것일까?

아니다.

### Switch

같은 LAN 안에서 여러 장비가 통신할 수 있도록 데이터를 전달한다.

### Gateway

다른 네트워크로 이동할 때 거치는 출입구 역할을 한다.

보통 가정이나 소규모 네트워크에서는 Router가 Default Gateway 역할을 한다.

---

# 내가 이해한 구조

```text
PC
 │
Switch
 │
Router
 │
WAN / Internet
```

정리하면

```text
Switch → LAN 내부 통신
Router → 서로 다른 네트워크 연결
Gateway → 다른 네트워크로 나가는 출입구
```

로 이해할 수 있다.
