# 네트워크 액세스 계층 (Network Access Layer)

## 네트워크 액세스 계층이란?

네트워크 액세스 계층(Network Access Layer)은 **TCP/IP 4계층 중 가장 하위 계층**으로, 실제 네트워크를 통해 데이터를 전송하는 역할을 담당한다.

이 계층은 **물리 계층(Physical Layer)**과 **데이터 링크 계층(Data Link Layer)**의 기능을 포함한다.

---

## TCP/IP 프로토콜 계층

TCP/IP 프로토콜은 다음과 같은 4계층으로 구성된다.

- 응용 계층 (Application Layer)
- 전송 계층 (Transport Layer)
- 인터넷 계층 (Internet Layer)
- 네트워크 액세스 계층 (Network Access Layer)

---

# 물리 계층 (Physical Layer)

## 역할

물리 계층은 **케이블이나 전파와 같은 물리적인 전송 매체를 통해 데이터를 전기 신호로 전송하는 계층**이다.

데이터를 실제로 전송하기 위한 기계적, 전기적, 기능적, 절차적 특성을 정의한다.

---

## 주요 기능

| 구분 | 설명 |
|------|------|
| 기계적 특성 | 케이블 종류, 커넥터, 핀의 개수 등을 정의 |
| 전기적 특성 | 전기 신호의 전압 및 특성을 정의 |
| 기능적 특성 | 각 핀이 수행하는 기능을 정의 |
| 절차적 특성 | 데이터 전송 절차와 동작 방식을 정의 |

---

# 데이터 링크 계층 (Data Link Layer)

## 역할

데이터 링크 계층은 **같은 네트워크(LAN) 내에서 데이터를 안정적으로 전달하는 역할**을 수행한다.

데이터를 **프레임(Frame)** 단위로 전송하며, 송신자와 수신자를 구분하기 위해 **MAC 주소**를 사용한다.

---

## 노드(Node)와 링크(Link)

- **노드(Node)** : 컴퓨터, 스위치, 공유기 등 네트워크에 연결된 장치
- **링크(Link)** : 노드와 노드를 연결하는 통신 경로

데이터 링크 계층은 노드 간 데이터를 전달한다.

---

## 사용되는 프레임 예시

| 구간 | 사용되는 프레임 |
|------|----------------|
| LAN | Ethernet Frame, Wi-Fi Frame |
| WAN | HDLC Frame, PPP Frame |

> 현재는 대표적인 프레임의 종류만 알아두면 충분하다.

---

## 주요 기능

- 프레임(Frame) 단위로 데이터 전송
- MAC 주소(48bit) 사용
- 오류 제어(Error Control)
- 흐름 제어(Flow Control)
- 타이밍 동기화(Synchronization)

---

## 핵심 정리

- 네트워크 액세스 계층은 TCP/IP의 가장 하위 계층이다.
- 물리 계층은 실제 신호를 전송한다.
- 데이터 링크 계층은 프레임 단위로 데이터를 전송한다.
- 데이터 링크 계층에서는 MAC 주소를 사용한다.
- 오류 제어와 흐름 제어를 수행하여 안정적인 통신을 지원한다.
