# 응용 계층 (Application Layer)

응용 계층(Application Layer)은 **사용자가 실행하는 응용 프로그램이 네트워크 서비스를 사용할 수 있도록 지원하는 계층**이다.

웹 브라우저, 이메일, 파일 전송 등 사용자가 직접 이용하는 서비스가 이 계층에서 동작한다.

---

## 응용 계층의 주요 기능

- 사용자와 네트워크 간의 인터페이스 제공
- 다양한 네트워크 서비스 제공
- 응용 프로그램 간 데이터 통신 지원
- 전송 계층(TCP, UDP)을 이용하여 데이터 송수신

---

## TCP 기반 응용 계층 프로토콜

TCP는 **연결형 서비스**를 제공하며, 신뢰성 있는 데이터 전송이 필요한 서비스에서 사용된다.

| 프로토콜 | 역할 |
|----------|------|
| HTTP | 웹 페이지 전송 |
| FTP | 파일 전송 |
| TELNET | 원격 접속 |
| SMTP | 이메일 송신 |
| POP | 이메일 수신 |

---

## UDP 기반 응용 계층 프로토콜

UDP는 **비연결형 서비스**를 제공하며, 빠른 전송이 필요한 서비스에서 사용된다.

| 프로토콜 | 역할 |
|----------|------|
| DNS | 도메인 이름을 IP 주소로 변환 |
| TFTP | 간단한 파일 전송 |
| DHCP | IP 주소 자동 할당 |
| SNMP | 네트워크 장비 관리 및 모니터링 |
| SNMP Trap | 장비의 이상 상태를 관리자에게 알림 |

---

## 핵심 정리

- 응용 계층은 **사용자가 네트워크 서비스를 이용할 수 있도록 지원하는 계층**이다.
- 전송 계층의 **TCP 또는 UDP**를 이용하여 데이터를 송수신한다.
- **TCP 기반 프로토콜**은 신뢰성이 중요한 서비스에서 사용된다.
- **UDP 기반 프로토콜**은 빠른 전송이 필요한 서비스에서 사용된다.
- 대표적인 응용 계층 프로토콜로 **HTTP, FTP, DNS, DHCP, SMTP** 등이 있다.
