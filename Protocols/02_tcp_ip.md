# 2. TCP/IP 프로토콜

## 연결형 서비스 프로토콜 (TCP)

### 통신 과정

- 요청
- 연결 설정
- 데이터 전송
- 연결 해제

### 특징

- 연결을 먼저 설정한 후 데이터를 전송한다.
- 오류 제어와 흐름 제어를 수행한다.
- 신뢰성이 높다.
- 대용량 데이터 전송에 적합하다.

### 예시

친구에게 전화를 걸어 연결을 맺고,

대화를 한 뒤,

전화를 끊는 과정과 같다.

---

## 비연결형 서비스 프로토콜 (IP)

### 통신 과정

- 데이터 전송

(별도의 연결 설정 과정이 없다.)

### 특징

- 연결을 설정하지 않는다.
- 빠르게 데이터를 전송한다.
- 오류 제어나 흐름 제어를 수행하지 않는다.
- TCP보다 신뢰성이 낮다.

### 예시

방송국은 데이터를 계속 송출하고,

사용자는 원하는 시점에 수신한다.

# 인터넷 TCP/IP 프로토콜 계층 구조

TCP/IP는 **4계층 구조**로 이루어진 인터넷 표준 프로토콜이다.

| TCP/IP 계층 | OSI 계층 |
|-------------|-----------|
| 응용 계층(Application) | 5~7계층 |
| 전송 계층(Transport) | 4계층 |
| 인터넷 계층(Internet) | 3계층 |
| 네트워크 액세스 계층(Network Access) | 1~2계층 |

---

## 핵심 정리

- TCP는 연결형 프로토콜이다.
- IP는 비연결형 프로토콜이다.
- 인터넷에서는 TCP와 IP가 함께 사용된다.
- TCP/IP 모델은 4계층으로 구성된다.
