# 3. OSI 7계층

## OSI(Open Systems Interconnection) 모델이란?

OSI 7계층은 네트워크 통신 과정을 7개의 계층으로 나누어 표준화한 모델이다.

각 계층은 독립적인 역할을 수행하며, 서로 협력하여 데이터를 전송한다.

---

## OSI 7계층 구조

| 계층 | 역할 |
|------|------|
| 7. 응용(Application) | 사용자에게 네트워크 서비스 제공 |
| 6. 표현(Presentation) | 암호화, 복호화, 압축, 인코딩 |
| 5. 세션(Session) | 세션 생성 및 유지 |
| 4. 전송(Transport) | 종단 간 데이터 전송(TCP, UDP) |
| 3. 네트워크(Network) | IP 주소와 경로 선택(Routing) |
| 2. 데이터 링크(Data Link) | MAC 주소, 오류 검출, 프레임 전송 |
| 1. 물리(Physical) | 전기 신호와 케이블을 통한 데이터 전송 |

---

## 프로토콜 계층 구조의 장점

- 시스템을 이해하기 쉽다.
- 설계와 구현이 편리하다.
- 표준 인터페이스를 제공한다.
- 기능을 단순화할 수 있다.
- 기능 업그레이드가 쉽다.
- 계층별 유지보수가 편리하다.

---

## 계층(Layer)이란?

계층(Layer)은 **특정 기능을 수행하는 논리적인 그룹**이다.

각 계층은 독립적인 기능을 수행하며,

- 상위 계층에는 서비스를 제공한다.
- 하위 계층의 서비스를 이용하여 동작한다.

---

## 핵심 정리

- OSI 모델은 7개의 계층으로 구성된다.
- 각 계층은 서로 다른 역할을 수행한다.
- 계층 구조를 사용하면 유지보수와 기능 확장이 쉽다.
