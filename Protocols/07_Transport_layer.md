# 전송 계층 (Transport Layer)

전송 계층은 **송신 측 프로세스와 수신 측 프로세스 간의 데이터 전송을 담당하는 계층**이다.

응용 프로그램 간의 통신을 지원하며, 연결 제어와 포트 번호를 이용한 데이터 전달을 수행한다.

---

## 프로세스(Process)란?

프로세스(Process)는 **실행 중인 응용 프로그램**을 의미한다.

예를 들어 웹 브라우저, 메신저, 게임 등이 실행되면 각각 하나의 프로세스로 동작한다.

---

## 전송 계층 프로토콜

전송 계층에서 사용하는 대표적인 프로토콜은 다음과 같다.

- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)
- SCTP (Stream Control Transmission Protocol)
- RTP (Real-time Transport Protocol)

---

## 전송 계층의 주요 기능

- 송신 측 프로세스와 수신 측 프로세스 간의 연결 제어
- 연결형 서비스와 비연결형 서비스 제공
- 응용 프로그램별 포트(Port) 번호 지정
- 데이터를 올바른 응용 프로그램으로 전달

---

## 연결형 서비스 (TCP)

연결을 먼저 설정한 후 데이터를 전송하는 방식이다.

### 특징

- 연결 설정 후 데이터 전송
- 오류 제어(Error Control)
- 흐름 제어(Flow Control)
- 높은 신뢰성
- 대용량 데이터 전송에 적합

---

## 비연결형 서비스 (UDP)

별도의 연결 과정 없이 데이터를 전송하는 방식이다.

### 특징

- 연결 설정 없이 데이터 전송
- 오류 제어와 흐름 제어를 수행하지 않음
- TCP보다 신뢰성이 낮음
- 빠른 데이터 전송 가능
- 실시간 통신 및 소량 데이터 전송에 적합

---

## 핵심 정리

- 전송 계층은 **프로세스 간 통신**을 담당한다.
- 대표적인 프로토콜은 **TCP와 UDP**이다.
- **TCP**는 연결형 서비스로 신뢰성이 높다.
- **UDP**는 비연결형 서비스로 빠른 전송이 가능하다.
- 포트 번호를 이용하여 데이터를 올바른 응용 프로그램으로 전달한다.
