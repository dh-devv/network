# 1. 네트워크 프로토콜(Network Protocol)

## 프로토콜(Protocol)이란?

프로토콜(Protocol)은 **네트워크에서 송신 측과 수신 측이 데이터를 주고받기 위해 미리 정한 통신 규칙(약속)** 이다.

사람들이 같은 언어와 대화 규칙을 사용해야 의사소통이 가능한 것처럼, 컴퓨터도 프로토콜을 사용해야 서로 통신할 수 있다.

---

## 예시

우편을 보낼 때는 편지를 봉투에 넣고 다음과 같은 정보를 함께 적는다.

- 보내는 사람
- 받는 사람
- 내용

인터넷에서도 이와 비슷하게 **데이터를 패킷(Packet)** 이라는 작은 단위로 나누어 전송한다.

패킷에는 다음과 같은 정보가 포함된다.

- 송신자(출발지)
- 수신자(목적지)
- 전송할 데이터

---

## 프로토콜의 3가지 요소

### 1. 구문(Syntax)

데이터의 형식과 표현 방법을 정의한다.

- 데이터 형식
- 데이터 포맷
- 부호화 방식
- 신호의 형태

➡️ **형식(Format)**

---

### 2. 의미(Semantics)

전송되는 데이터가 어떤 의미를 가지는지 정의한다.

- 데이터의 의미
- 각 필드의 역할
- 명령과 응답의 의미

➡️ **내용(Meaning)**

---

### 3. 타이밍(Timing)

데이터를 언제, 어떤 속도로 전송할지를 정의한다.

- 전송 속도
- 송·수신 타이밍
- 동기화

➡️ **시간(Time)**

---

## 프로토콜 설계 시 고려사항

- 전송 데이터 포맷 구성
- 주소 표현 방법
- 데이터 전송 오류 제어 방법
- 데이터 흐름 제어 방법
- 데이터 전달 타이밍 방식

---

## 프로토콜의 주요 기능

- 데이터 분할(Fragmentation)
- 데이터 재조립(Reassembly)
- 캡슐화(Encapsulation)
- 디캡슐화(Decapsulation)
- 연결 제어(Connection Control)
- 흐름 제어(Flow Control)
- 오류 제어(Error Control)
- 주소 설정(Addressing)
- 동기화(Synchronization)
- 다중화(Multiplexing)

### 데이터 분할 및 재조립 예시

MTU가 **1500Byte**인 네트워크에서 **5000Byte** 데이터를 전송해야 한다면 여러 개의 패킷으로 분할하여 전송한다.

수신 측에서는 분할된 패킷을 다시 조립하여 원래 데이터로 복원한다.

---

## 핵심 정리

- 프로토콜은 컴퓨터 간 통신 규칙이다.
- 데이터를 안전하고 효율적으로 전달하기 위한 약속이다.
- 프로토콜은 구문, 의미, 타이밍으로 구성된다.
- 인터넷은 데이터를 패킷(Packet) 단위로 전송한다.
