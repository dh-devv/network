# 네트워크 계층 (Network Layer)

네트워크 계층은 **상위 계층(전송 계층)**에서 전달받은 데이터에 **IP 헤더를 추가하여 IP 패킷(Packet)**을 생성하고, 목적지까지 데이터를 전달하는 역할을 한다.

---

# 주요 역할

- 송신 측: IP 패킷 생성(조립)
- 수신 측: IP 패킷 분해
- 목적지 IP 주소를 이용하여 최적의 경로(Routing) 설정
- 네트워크 인터페이스에 IP 주소 할당
- IP 주소를 이용한 네트워크 접속 제어 및 보안 기능 수행

---

# 주요 기능

- 목적지 IP 주소를 기반으로 최적의 경로를 선택한다.
- 서로 다른 네트워크 간 데이터를 전달한다.
- IP 패킷을 생성하고 목적지까지 전송한다.

---

# 네트워크 계층 프로토콜

- IPv4
- IPv6
- ICMP
- ARP
- RARP
- IGMP
- RIP
- OSPF

---

# IPv4

## 특징

- 비연결형(Connectionless) 서비스를 제공한다.
- 목적지 IP 주소를 이용하여 경로를 설정한다.
- IP 패킷의 조립 및 분해를 수행한다.

### 지원 프로토콜 번호

| 번호 | 프로토콜 |
|------|----------|
| 1 | ICMP |
| 6 | TCP |
| 17 | UDP |
| 89 | OSPF |

### 주소 체계

- **32비트** 주소 사용
- **8비트 × 4개 블록**으로 구성
- 점(`.`)으로 구분
- 각 블록은 **0 ~ 255** 범위를 가진다.

**예시**

```
192.168.0.10
```

---

# IPv6

## 특징

- 비연결형 서비스를 제공한다.
- IPv4보다 주소 공간이 매우 크다.
- 보안 기능(IPSec)을 기본적으로 지원한다.
- QoS(서비스 품질) 기능이 강화되었다.
- 자동 주소 설정(Auto Configuration)을 지원한다.
- 헤더 구조가 단순해져 처리 속도가 향상되었다.

### IPv4와 IPv6 비교

| IPv4 | IPv6 |
|------|------|
| 32비트 주소 | 128비트 주소 |
| 보안 기능 선택 사항 | 보안 기능 기본 지원 |
| 주소 부족 | 매우 넓은 주소 공간 |
| 헤더 구조 상대적으로 복잡 | 헤더 구조 단순 |

### 주소 체계

- **128비트** 주소 사용
- **16비트 × 8개 블록**으로 구성
- 콜론(`:`)으로 구분
- 각 블록은 **16진수(Hexadecimal)** 로 표현한다.

**예시**

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

# ICMP (Internet Control Message Protocol)

인터넷에서 **오류 보고(Error Reporting)** 와 **네트워크 상태 확인(Network Diagnostics)** 을 수행하는 프로토콜이다.

## 주요 기능

| 오류 보고 메시지 | 질의 메시지 |
|-----------------|------------|
| 네트워크 오류를 보고 | 네트워크 상태를 확인 |

### 예시

- `ping` 명령어
- Echo Request
- Echo Reply

---

# IGMP (Internet Group Management Protocol)

멀티캐스트 그룹을 관리하기 위한 프로토콜이다.

## 멀티캐스트와 브로드캐스트 비교

| 멀티캐스트 | 브로드캐스트 |
|------------|-------------|
| 등록된 그룹에만 데이터 전송 | 모든 호스트에게 데이터 전송 |

### 활용 예시

- 영상 회의
- IPTV
- 멀티미디어 스트리밍
- 라우팅 정보 전달

---

# ARP (Address Resolution Protocol)

**IP 주소를 이용하여 MAC 주소를 찾는 프로토콜**이다.

### 동작

```
IP 주소
      ↓
ARP
      ↓
MAC 주소
```

---

# RARP (Reverse Address Resolution Protocol)

**MAC 주소를 이용하여 IP 주소를 찾는 프로토콜**이다.

기존에는 주로 디스크가 없는 장비에서 사용되었으며, 현재는 대부분 **DHCP**가 이를 대체한다.

### 동작

```
MAC 주소
      ↓
RARP
      ↓
IP 주소
```

# 라우팅 프로토콜

라우터가 목적지까지의 **최적 경로를 선택**하기 위해 사용하는 프로토콜이다.

## 주요 기능

- 라우터 간 경로 정보 교환
- 최적 경로 계산
- 라우팅 테이블 관리

### 대표 프로토콜

- RIP
- OSPF

#### RIP

- 거리 벡터(Distance Vector) 방식
- **Hop Count(거치는 라우터 수)** 를 기준으로 최적 경로를 선택한다.

#### OSPF

- 링크 상태(Link State) 방식
- 네트워크 상태를 분석하여 최적 경로를 계산한다.

---

# 핵심 정리

- 네트워크 계층은 **IP 주소를 이용하여 목적지까지 데이터를 전달하는 계층**이다.
- IPv4는 **32비트**, IPv6는 **128비트** 주소를 사용한다.
- **ICMP**는 오류 보고 및 네트워크 진단에 사용된다.
- **ARP**는 **IP → MAC 주소**를 변환한다.
- **RARP**는 **MAC → IP 주소**를 변환한다.
- **IGMP**는 멀티캐스트 그룹을 관리한다.
- **RIP**는 최소 Hop Count를 기준으로 경로를 선택한다.
- **OSPF**는 링크 상태 정보를 이용하여 최적 경로를 계산한다.
